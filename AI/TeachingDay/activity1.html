Activity 1
Build a worksheet faster
Welcome | Overview | Prompting tips | Departmental guidance

Goal

Test whether an LLM can save preparation time when drafting a worksheet or problem sheet for a specific course.

Verification reminder. All mathematical claims, solutions, and code should be checked independently by a human.

Suggested task

  1. Choose one course you actually teach.
  2. Choose one topic for a 20-30 minute worksheet.
  3. Ask the LLM for a first draft.
  4. Check mathematical correctness, level, notation, and progression.
  5. Discuss what was genuinely useful and what still required human work.

Example prompt

I teach a first course in calculus. Create a short worksheet on implicit differentiation for university students. Include: 2 warm-up exercises, 2 medium exercises, 1 challenge exercise, and a brief solution sketch for the teacher. Keep notation standard and avoid applications that require physics background.

Questions for the group

  • Did the LLM choose an appropriate level?
  • Were the exercises mathematically correct?
  • Did the sequence definition → example → exercise make sense?
  • How much editing would still be needed before classroom use?

Minimum output expected from the group

  • One example of a useful time-saving output
  • One mathematical or pedagogical issue that required correction
  • One rule of thumb for responsible classroom use
