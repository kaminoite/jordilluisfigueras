# Procedència dels recursos visuals

Identitat visual de referència: [Estalmat Catalunya](https://www.estalmat.cat/). La paleta original utilitza el blau `#2A8CCE`, blanc i text fosc; els títols utilitzen Cirka i el text Titillium Web. El calendari incorpora aquests recursos i formes arrodonides, amb un blau més fosc per als textos i botons per afavorir la llegibilitat.
